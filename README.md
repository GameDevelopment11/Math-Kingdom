# Math Kingdom

**Tagline:** Solve equations, defend your kingdom, and become a mathematical hero!

## Game Description

Math Kingdom is a 2D educational strategy and adventure game in which players defend a fantasy kingdom against invading monsters by solving mathematical challenges.

The player acts as the kingdom's commander, building defenses, recruiting units, and unlocking magical abilities using mathematical knowledge.

As the game progresses, challenges become more difficult, introducing arithmetic, fractions, equations, and logical reasoning.

## Gameplay

Players progress through five levels, each representing a different region of the kingdom.

To defeat enemies, players must solve mathematical problems. Correct answers generate resources, activate defenses, and strengthen their army.

For example, a player might solve `8 × 7 = 56` to activate an archer tower before an enemy reaches the castle.

Players must balance mathematical accuracy, resource management, and strategic decisions to protect their kingdom.

## Target Audience

Students aged 10–16 who want to improve their mathematical skills through interactive gameplay.

## Main Features

- Five progressively challenging levels
- Mathematical puzzles integrated into combat
- Resource management and defensive structures
- Different enemies and mathematical challenges
- Rewards and progression system
- Educational hints and feedback

## Platform

Web browsers on desktop computers.
